## Repo Structure

```
index.html              ← Homepage (episode list + featured episode)
feed.xml                ← RSS/podcast feed (Spotify, Apple Podcasts)
video-feed.xml          ← YouTube RSS feed
episodes.json           ← Source of truth for all episode metadata
sitemap.xml             ← Auto-generated, keep in sync
style.css               ← Shared stylesheet (some pages use inline styles)
about/                  ← About page
episodes/               ← Two types of episode pages (see below)
tests/                  ← Test suite (run before every push)
```

### Episode Pages — TWO Types

**Type 1: Directory-based (canonical, SEO)**
- Path: `episodes/<slug>/index.html`
- Example: `episodes/16-brazil-floods-offline-diagnostics-india-ai-probe/index.html`
- Generated by: `step-create-episode-page.sh` in the pipeline

**Type 2: Numbered shortlinks**
- Path: `episodes/1.html`, `episodes/2.html` ... `episodes/16.html`
- Also at root: `1.html` through `16.html` (legacy redirects)
- These are lightweight pages or redirects to the canonical URL

**Do NOT confuse them.** Design changes go to both types.

## Key Files

### `episodes.json`
Single source of truth for all episodes. Each entry has:
- `number`, `title`, `slug`, `date`, `description`, `rss_description`
- `mp3_url`, `audio_size_mb`, `duration`
- `youtube_url`, `youtube_id`
- `substack_url`, `tweet_url`
- `keywords`, `headline`, `theme`, `top_stories`
- `pipeline_status`, `pipeline_started`

**Never manually edit episode content** — regenerate from episodes.json using pipeline scripts.

### `feed.xml`
Podcast RSS feed. **NEVER manually edit.** Always regenerate via:
```bash
python3 ~/.openclaw/workspace/impact-signal/pipeline/generate-rss-incremental.py
```
RSS pubDate must be 14:00 UTC (= 6am PT). Never use 7am UTC.

### `index.html`
Homepage. Updated by:
```bash
python3 ~/.openclaw/workspace/impact-signal/pipeline/step-update-homepage.py
```
